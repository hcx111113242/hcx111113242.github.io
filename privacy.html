隐私说明

OpenWrt Briefing 是个人自用的简报收件与长图工具。本说明介绍工具访问哪些数据、数据保存在哪里，以及用户如何撤销访问和管理已保存文件。

Gmail 访问权限与实际筛选范围

工具使用 Gmail 只读权限 https://www.googleapis.com/auth/gmail.readonly。该权限在技术上允许读取已授权账号的整个邮箱；Google 的授权并未按发件人、主题或某几封邮件限制读取范围。

程序实际按用户配置的确切发件人与主题条件筛选 A 股、美股、AI 三类简报，并读取匹配邮件以生成完整长图。这些筛选由程序执行，不能等同于 Google 授权层面的邮件范围限制。

设备保存与 Telegram 投递

  • 本地及用户控制的 OpenWrt 设备：保存 OAuth 授权 token、匹配的邮件正文、PNG 缓存及投递状态，用于读取简报、生成图片与避免重复投递。
  • Telegram：仅将简报 PNG 发送至用户唯一绑定的 Telegram 私聊。发送后，文件也会保存在 Telegram 平台及用户自行下载的设备中。

缓存与文件由用户自行管理。本工具没有固定的数据保留时长，也不承诺在某个期限后自动删除缓存、投递记录或 Telegram 中的文件。

数据用途

工具使用匹配邮件的内容生成便于阅读的长图，并记录投递结果。它不使用 AI 改写邮件，不将邮件内容用于模型训练，也不售卖用户数据。

本应用从 Google API 获得的信息的使用和转移遵循 Google API Services User Data Policy，包括 Limited Use 要求。

本说明页面不运行 JavaScript，不包含跟踪器、表单或远程加载的资源。

撤销授权与管理已保存的数据

用户可以在 Google 账号的第三方应用与服务访问设置中撤销本工具的授权。撤销生效后，工具无法继续通过该授权获取新邮件。

撤销授权不会自动删除已经保存在本地或 OpenWrt 上的正文、PNG 缓存及投递记录，也不会自动删除已经发送到 Telegram 的文件。用户需要分别管理设备上的文件、Telegram 聊天中的文件以及自行下载的副本。

Google 与 Telegram 平台

Google 与 Telegram 各自平台上的数据处理、保存与删除受各自的政策及账号设置约束。本工具的授权撤销或本地文件删除，不代表相应平台上的副本也已删除。
